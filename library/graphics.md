# Graphics library (reusable scenes and elements)

Copy a scene file into a new project's `compositions/`, change the text, keep the cue logic.
Each scene animates on `c[i]` = start of line i of that scene in `script.json` (see the skill).
If your new scene has a different number of lines, re-point the `c[...]` indices.

## Promo style (`videos/conversion-tracking-promo/compositions/`)

| Scene file | Lines | What it shows | Reuse for |
| --- | --- | --- | --- |
| `hook.html` | 4 | headline mask reveal, 2 stat cards with count-up, not-equal badge, error card, in-scene orange panel wipe with a 3-node vertical flow and a pulsing break marker | any "numbers do not match" or "something is broken" opener |
| `intro.html` | 4 | "Hi, I'm" + 2-line name reveal, orange role pill, then the title shrinks and a hub diagram draws (1 > 1 > 3 nodes), 3 colored value pills | personal intro, "how it connects" |
| `stack.html` | 5 | 3-line headline, 10 paper tool cards popping in pairs on each line | tools, services, features, logos-as-text |
| `problems.html` | 6 | statement slide, then 4 full color panels (orange, lime, magenta, orange), each a 2-word headline + subline + rotated paper card with its own mini illustration, end statement with an orange pill | listicles, "4 problems", case studies |
| `method.html` | 7 | headline, 5 step pills with an orange highlight that slides step to step, a 4-node trace path, then QA checklist (ticks) + dark code card | process, workflow, timeline, "how I work" |
| `evidence.html` | 5 | headline + subline, 4-step proof ladder (dashed "not enough" first, lime "done" last), then a documentation card | proof, guarantees, before/after logic |
| `cta.html` | 3 | "Sound familiar?" + 3 pain cards, then a center circle wipe to the magenta end card: name, role, orange button, URL | every ending (hold 3 s+) |
| `captions.html` | auto | generated by build.mjs, one line at a time, spoken word in an orange pill | always on |

Mini illustrations inside `problems.html` (copy the inner markup): checkout boundary with a blocked token,
duplicate event log with an "x2" flag, 3-point timeline with a red "too early" dot, form fields to CRM fields with "empty" rows.

Shared building blocks (CSS in the index generated by `build.mjs`): `.wipe` + `.fill` (color panel with circle wipe),
`.paper` (white card), `.glass` (translucent card behind), `.pill`, `.ast` (asterisk mark), `.demo` (DEMO DATA tag), `.big` (headline).
Tokens and motion timings: `docs/style-color-block-promo.md`.

## Dark-tech style (`videos/conversion-tracking-portfolio/compositions/`)

Same 7 scene roles (hook, intro, stack, problems, method, evidence, cta) in navy + blue, Inter, calm fades, no SFX.
Use for serious B2B or technical audiences.

## Sound effects vocabulary (promo `scripts/sfx.py`)

`whoosh` scene or panel wipe (auto on every scene change), `swoosh` card slides in, `pop` element appears,
`tick` checkmark or step change, `ding` success or final confirmation, `thud` error, mismatch, broken.
Declare per scene: `const SFX = /*SFX*/[["pop","c[1]+0.2",0.7]]/*ENDSFX*/;` (name, time, optional gain).

## Music

`scripts/music.py`: promo = 100 BPM light pop (kick, clap, hats, plucked C G Am F, sub bass);
dark = slow ambient pad. Both synthesized, no licensing. Volume 0.16 (promo) under the voice.
